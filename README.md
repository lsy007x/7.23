# TAMSAEK – H

문화유산의 단어를 쉽게 이해하다. 전통 건축 용어를 **사전 정의 + 구조상 위치(도면·3D)** 로 함께 보여 주는 모바일 전용 웹입니다.

## 기능

| 화면 | 내용 |
|---|---|
| 홈 (`#/`) | TAMSAEK – H 제목, 검색창, 대주제 버튼(석조·목조·불상·사찰), AI 기능 바로가기 |
| 대주제 (`#/c/stone`) | 상단 카테고리 탭, "현재 주제 + 검색창", 소주제 버튼, 전체 용어 목록 |
| 도면 (`#/c/stone/pagoda`) | **인터랙티브 도면**: 부재나 이름을 탭하면 해당 부재만 금색 엣지로 빛나고 나머지는 반투명, 아래에 상세 설명 패널. 상륜부·탑신부·기단부 같은 그룹을 탭하면 구성 부재 전체가 함께 강조됨 |
| 3D (`#/c/wood/frame`) | **정면 3칸 · 1고주 5량가 3D 모델** (three.js). 고주·퇴보·대들보·동자주·종보·대공·도리·어칸/협칸/퇴칸 등을 탭하거나 칩을 눌러 위치 확인 |
| AI 태깅 (`#/ai/tag`) | 답사 사진·도면·보고서 캡처 업로드 → Claude 비전이 부재를 인식해 **용어집 id로만** 태그 (신뢰도·위치 표시) |
| AI 튜터 (`#/ai/tutor`) | **RAG**: 질문에서 용어집 항목을 먼저 검색해 그 문서만 근거로 답변, 문장마다 `[용어]` 출처 링크. 서버가 없으면 검색된 용어집 원문을 그대로 보여 줌 |

소주제: 석조 – 석탑·석등·부도·석비 / 목조 – 량가 구조(3D)·공포 / 불상 – 불상 각부 / 사찰 – 문·불전·기타 전각

## 실행

```bash
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start      # http://localhost:8080
```

- API 키는 서버에만 둡니다. 키가 없어도 검색·도면·3D는 모두 동작하고, AI 기능만 안내 메시지/용어집 원문으로 대체됩니다.
- 모델 기본값은 `claude-opus-5-5` (`TAMSAEK_MODEL`로 변경 가능). 거절 시 서버측 대체 모델(`fallbacks: "default"`)이 켜져 있습니다.
- `public/` 폴더만 정적 호스팅해도 AI를 제외한 기능은 동작합니다.

## 구조

```
server.mjs            정적 파일 + /api/tag (비전 태깅, 구조화 출력) + /api/ask (RAG 튜터)
public/js/data.js     용어 지식 베이스 (검색·도면·RAG·태깅이 공유)
public/js/rag.js      검색/문맥 검색 (브라우저·서버 공용)
public/js/diagrams.js 인터랙티브 SVG 도면 + 하이라이트
public/js/model3d.js  1고주 5량가 3D 모델
public/js/app.js      라우터와 화면
test/                 데이터 무결성·검색 테스트 (npm test)
```

## 용어 데이터에 대해 (중요)

`public/js/data.js`의 정의는 일반 개설서 수준의 **편집 초안**이며, 각 항목의 `source`가
"국가유산청 표준 용어 대조 필요"로 표시되어 있습니다. 튜터는 이 데이터 밖의 내용을 답하지 않도록
제한되어 있으므로, 국가유산청 표준 용어집·학술 자료와 대조해 정의와 `source`를 갱신하면 그대로 답변 품질이 올라갑니다.
용어를 추가하면 검색·튜터·태깅에 자동 반영되고, 도면/3D에 표시하려면 `diagrams.js`/`model3d.js`에 `data-id`를 가진 부재를 추가합니다.
