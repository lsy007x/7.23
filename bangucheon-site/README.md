# 반구천의 암각화 — 바위의 기억, 과학으로 지키다

유네스코 세계유산 「반구천의 암각화」(울주 대곡리 반구대 암각화 · 울주 천전리 명문과 암각화)의
문양·세계유산 등재 과정·보존과학을 소개하는 인터랙티브 전시 웹페이지. 자체 완결형 단일 `index.html`.

## 구성 (기획서 기반)

| 페이지 | 내용 |
|---|---|
| **표지** | 큰제목/부제 + 중심 페이지로 가는 진입 버튼 |
| **2-1 유산 지도** | 반구천 지도 위 두 유산의 인터랙티브 마커(핑) → 클릭 시 요약 + 상세 이동 |
| **2-2 문양 탐색** | 카테고리 탭 + 도면 속 문양 클릭 → 해당 문양만 금빛으로 빛나고 설명 표시 |
| **2-3 세계유산 등재** | 1965→2025 등재 과정 인터랙티브 타임라인 + 등재기준(i·iii) 해설 |
| **2-4 보존과학** | 지질·풍화 진단, 정량 데이터(39,027㎠/2,009㎠/1.2%), 전공자용 외부 링크 |
| **마무리** | 유산의 가치와 스토리라인 마무리 |

## 실행

가장 간단한 방법 — **`index.html`을 더블클릭**하면 브라우저에서 바로 열립니다
(외부 파일을 불러오지 않는 자체 완결형이라 서버가 필요 없습니다).

서버로 열고 싶다면:

```bash
cd bangucheon-site
python3 serve.py          # http://localhost:8000
```
